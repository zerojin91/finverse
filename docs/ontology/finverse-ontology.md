# FINVERSE 시나리오 온톨리지

## 목적

FINVERSE는 사용자의 질문에 맞는 자료를 모은 뒤, 현재 시장 상황을 구조화하고 MiroFish 시뮬레이션으로 미래 시나리오를 만든다.

핵심 순서는 다음과 같다.

```text
사용자 질문
  → 질문에 맞는 검색 범위 결정
  → 시장·경제·외부 사건·사람들의 심리 정보 수집
  → 현재 시장 상황 온톨리지 구성
  → MiroFish 시뮬레이션
  → 사용자 질문에 맞는 미래 시나리오 생성
```

## 네 가지 기본 개념

### 네 가지 개념의 연결관계

[관계도 원본 이미지 열기](./finverse-four-concepts.svg)

네 가지 영역은 각각 따로 존재하지만, 실제 시장 상황에서는 서로 영향을 주고받는다.

### 1. 시장

시장에서 실제로 무엇이 얼마나 움직였는지를 나타낸다.

- 지수: KOSPI, KOSDAQ 등
- 섹터: 반도체, 금융, 자동차 등
- 종목
- 일별 시가·고가·저가·종가·거래량
- 외국인·기관 수급
- 변동률과 변동성
- 최소 1년 이상의 과거 흐름
- 큰 움직임과 연결된 과거 이벤트

#### 권장 수집원

- [한국거래소 KRX Data Marketplace](https://data.krx.co.kr/): KOSPI·KOSDAQ 지수, 종목 가격, 거래량, 투자자별 수급, 업종·시장 통계
- [KRX Open API·Open KRX](https://open.krx.co.kr/): 한국거래소 데이터 접근 경로와 제공 범위 확인
- [DART 전자공시시스템](https://dart.fss.or.kr/): 기업 실적, 사업보고서, 주요 공시와 투자 관련 내용
- 보조 데이터: 사용 권한이 확보된 상용 시세 API 또는 공개 금융 데이터 제공처

시장 데이터는 공식 거래소 데이터를 우선하고, 보조 데이터와 값이 다르면 수집 시각·수정 여부·산출 기준을 함께 기록한다.

### 2. 경제

시장에 영향을 주는 경제적 배경을 나타낸다.

- 환율
- 기준금리
- 단기 국채 수익률
- 5년·10년 국채 수익률
- 물가상승률
- 고용지표
- 경기지표
- 시장 예상값과 실제 발표값의 차이
- 현재 수준과 과거 수준의 비교

#### 권장 수집원

- [한국은행 ECOS](https://ecos.bok.or.kr/): 기준금리, 환율, 국채 수익률, 물가, 국민계정과 주요 경제 시계열
- [KOSIS 국가통계포털](https://kosis.kr/): 물가, 고용, 산업생산, GDP 등 국내 공식 통계
- [미국 연방준비은행 FRED API](https://fred.stlouisfed.org/docs/api/fred/overview.html): 미국 금리, 물가, 고용과 글로벌 거시지표
- 각국 중앙은행·통계청·정부 부처: 해당 국가의 기준금리, 물가, 고용과 정책 통계

경제지표는 발표일, 기준일, 단위, 계절조정 여부, 예상값, 실제값, 수정 발표 여부를 함께 저장한다.

### 3. 외부 사건

시장 움직임의 원인이 될 수 있는 사건을 나타낸다.

- 뉴스
- 기업 실적과 전망
- 기업 투자·CapEx
- 정책과 규제
- 무역분쟁
- 전쟁·지정학적 리스크
- 공급망 이슈
- 기관·외국계 분석

각 사건에는 발생 시각, 출처, 관련 시장·섹터·종목, 예상 영향, 실제 시장 반응을 함께 기록한다.

#### 권장 수집원

- 기업 공식 공시·IR·실적 발표: 실적, 전망, 투자·CapEx, 공급계약과 경영진 발언
- 정부·중앙은행·국제기구 공식 발표: 정책, 규제, 금리 결정과 지정학 관련 공식 자료
- [DART 전자공시시스템](https://dart.fss.or.kr/): 국내 기업 공시와 실적 자료
- 신뢰도 높은 뉴스: Reuters, AP, 연합뉴스, Bloomberg 등. Bloomberg는 라이선스가 있는 경우 우선 활용
- 웹 검색 도구: Google·DuckDuckGo는 사건을 찾는 탐색용으로 사용하고, 최종 근거는 원문 출처로 확인

뉴스 제목만 저장하지 않고 원문 링크, 작성·발표 시각, 사건의 사실, 해석, 시장 반응을 분리해 기록한다.

### 4. 사람들의 심리(커뮤니티)

사람들이 시장을 어떻게 받아들이고 있는지를 나타낸다.

- 관련 종목·섹터 언급량
- 긍정·부정 반응
- 공포와 낙관
- FOMO
- 군집행동
- 투자자들의 기대 방향
- 심리 변화 속도

커뮤니티 반응은 시장의 사실이 아니라 투자자 심리의 관측값으로 사용한다.

#### 권장 수집원

- [Reddit Data API](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki): 종목·섹터 언급량, 게시글·댓글 감성, 반복되는 주장
- [Twitch Helix API](https://dev.twitch.tv/docs/api/reference/): 금융 스트리머 채널과 채팅 등 실시간 반응. 접근 권한과 이용약관을 준수한다.
- 국내 커뮤니티·뉴스 댓글: 공개 범위와 서비스 약관을 지키는 경우에 한해 보조 자료로 활용
- 네이버 데이터랩·검색량 데이터: 종목·섹터에 대한 관심도와 갑작스러운 검색 증가 확인

커뮤니티 자료는 사실 확인 자료가 아니라 심리 자료다. 언급량이 많다는 사실과 실제 시장 방향을 동일하게 취급하지 않으며, 봇·중복 게시·소수 의견의 과대표집 가능성을 함께 표시한다.

## 검색 원칙

사용자 질문에 포함된 조건을 가장 먼저 검색한다. 질문에 직접 나오지 않았더라도 분석에 꼭 필요한 정보는 자동으로 보완 검색한다. 영향이 작거나 신뢰할 자료가 부족한 정보는 중립으로 처리한다.

```text
사용자 지정 정보
  → 반드시 검색

분석에 필요한 누락 정보
  → LLM이 판단해 추가 검색

영향이 작거나 근거가 부족한 정보
  → 중립 처리
```

검색 결과는 가능한 한 출처, 수집 시각, 관련 대상, 영향 방향과 함께 저장한다.

### 히스토리컬 데이터 수집 원칙

- 시장·섹터·종목·경제지표는 가능한 한 과거 데이터를 함께 수집한다.
- 가격 데이터는 일 단위 시가·고가·저가·종가·거래량을 기본으로 수집한다.
- 수집 기간은 최소 1년으로 하고, 데이터가 허용하는 범위에서 길수록 좋다.
- 큰 움직임과 이벤트의 연결을 보기 위해 시장 변화는 주 단위로도 정리한다.
- 여기서 이벤트는 시장의 큰 상승·하락 또는 추세 전환을 의미한다.
- 큰 움직임이 발생한 경우 해당 시점의 뉴스·정책·경제 변화·수급·심리를 찾아 원인을 분석한다.
- 과거 이벤트의 영향 방향·강도·지속기간을 확인하고, 현재 시나리오와 유사한 경우 미래 시나리오의 근거로 반영한다.
- 과거 결과를 미래의 정답으로 사용하지 않고, 현재 조건과의 차이를 함께 표시한다.

## 핵심 관계

```text
외부 사건 → 경제
외부 사건 → 시장
경제 → 시장
시장 → 사람들의 심리
사람들의 심리 → 시장
과거 유사 사례 → 현재 상황 해석
현재 시장 상황 + 사용자 조건 → MiroFish
MiroFish 시뮬레이션 → 미래 시나리오
```
