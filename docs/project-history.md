# FINVERSE 프로젝트 히스토리와 방향

이 문서는 구현 세부보다 제품 의도와 누적된 주요 결정을 보존한다. 작업 전 `AGENTS.md`와 함께 읽고, 새 방향을 추가할 때는 날짜·결정·이유·영향을 남긴다.

## 제품 방향

- FINVERSE는 실제 시장 자료를 바탕으로 사용자가 금융 판단을 연습하는 이벤트 시나리오 플랫폼이다.
- 미래를 예언하는 서비스가 아니라, 과거·현재 데이터에서 근거를 만들고 불확실한 사건과 시장 참여자의 상호작용을 관찰하는 연습 도구다.
- LLM은 자료의 맥락화, 에이전트 반응, 시나리오 서술을 담당한다. 가격·사건·수익률을 확정적으로 약속하지 않는다.

## 현재 사용자 흐름

`종목 선택 → 실제 자료 준비 → 투자 상태 → 시뮬레이션 설정 → 모의 투자`

- 종목 선택 후 최근 실제 OHLC 캔들을 먼저 보여준다.
- 자료 준비 단계에서 시장·경제·사건·커뮤니티의 실제 적재 건수와 기준 시점을 보여준다.
- 캐시 응답이어도 각 단계는 최소 대기 시간을 유지해 사용자가 순차적으로 이해하도록 한다.
- 투자 상태는 명시적으로 확정해야 다음 단계가 열린다.
- 시뮬레이션 설정에서는 10·20·60거래일을 고르고, 시장 참여 에이전트는 개인 투자자·외국인·기관·연기금 4개 범주로 구성한다.

## 데이터와 맥락 원칙

- 데이터의 중심은 원격 AWS PostgreSQL의 `lake.records`와 동기화된 도메인 뷰다.
- 시장·경제·사건·커뮤니티 자료의 건수는 실제 DB 조회 결과이며, 이벤트와 커뮤니티는 종목별 데이터가 아닌 시장·일별 집계가 섞일 수 있으므로 UI에서 범위를 과장하지 않는다.
- 초기 상황 맥락은 선택 종목의 네 도메인 자료를 종목 타깃형 Evidence Markdown으로 먼저 만들고, 그 문서를 OpenRouter로 분석한다. 결과에는 현재 추세, 수급, 주요 이슈, 위험, 긴장 관계, 불확실성, 관찰 포인트와 문서 근거 목록을 포함한다.
- 초기 상황의 종합 분석은 네 Evidence Markdown이 모두 준비된 뒤에만 시작한다. 이 분석은 종목 전체 현황과 최근 한 달의 `종목 이벤트 시퀀스`를 함께 반환하며, 이벤트는 문서에서 확인된 실제 흐름과 문서 종합 해석을 구분해 표시한다.
- 초기 상황 최상단은 긴 문단 대신 실제 근거와 그 의미를 함께 담은 음슴체 `5줄 요약`으로 먼저 보여준다.
- 초기 맥락은 입력 데이터 지문과 스키마 버전으로 12시간 캐시하며, 시나리오 시작 시 화면에서 확인한 맥락을 게임에 저장한다.

## 에이전트·시나리오 방향

- 참여 에이전트는 MiroFish형 상호작용 컨셉을 차용하되 현재 모의투자 엔진은 결정론적 체결 엔진과 OpenRouter 기반 반응 생성의 결합이다.
- 개인 투자자·외국인·기관·연기금은 서로 다른 위험 회피도, 심리 반감기, 이벤트 반응도, 전략을 가진다.
- 기간별 사건 수와 내부 에이전트 수는 사용자에게 복잡한 조정값으로 노출하지 않고 엔진이 구성한다.
- 향후 무작위 사건을 추가할 때도 완전한 무작위가 아니라 수집된 맥락·시나리오 제약·시장 데이터에 근거한 재현 가능한 난수 시드와 출처를 남기는 방향을 우선한다.

## 작업 기록

### 2026-09-05 — Evidence 문서 완료 후 초기 상황 종합 분석으로 분리

- 시장·경제·사건·커뮤니티 Evidence Markdown 준비와 OpenRouter 종합 분석을 별도 API 단계로 분리했다.
- 화면은 네 문서를 순차적으로 보여준 뒤 종합 분석 결과인 전체 요약, 종목 이벤트 시퀀스, 위험 요인, 관찰 포인트를 채운다.
- 종목 이벤트 시퀀스는 미래를 생성하지 않고 최근 한 달 문서의 실제 사건·지표·반응만 사용하며, 직접 관측과 문서 종합 해석을 구분한다.

### 2026-09-05 — 초기 상황·현재 맥락 분석 추가

- 선택 종목의 실제 4개 데이터 영역을 OpenRouter가 구조화된 JSON으로 요약하도록 추가했다.
- 분석 결과를 12시간 캐시하고, 화면과 생성된 게임에서 동일한 초기 맥락을 사용하도록 연결했다.
- 로컬 DB는 SSH 터널 `127.0.0.1:15432`를 통해 접근한다. 백엔드 재시작 때 터널 오버라이드가 빠지면 PostgreSQL 연결 타임아웃이 발생하므로 실행 스크립트에서 양쪽 서버에 같은 DB URL을 주입하도록 보강했다.

### 2026-09-05 — 초기 맥락을 종목 타깃 Evidence 문서 기반으로 통합

- 기존 온톨로지 파이프라인의 Evidence Markdown 계약을 모의투자 초기 맥락에도 적용했다.
- 선택 종목별로 시장·경제·사건·커뮤니티 원자료 문서를 캐시 디렉터리에 만들고, LLM은 문서를 근거로 초기 상황을 분석한다.
- 전체 온톨로지·GraphRAG 실행을 중복 호출하지 않고 동일한 데이터·문서 구조를 공유하는 1차 통합으로 구성했다. 이후 에이전트 프로필·미래 사건 생성도 이 문서와 분석 결과를 재사용한다.

### 2026-09-03 — 설정 화면 순차 공개와 에이전트 카드

- 캔들·자료 수집·투자 상태·시뮬레이션 설정을 순차적으로 공개하고, 캐시가 빨라도 최소 대기 시간을 유지했다.
- 기존 4개 연습 유형 선택 대신 시장 참여 에이전트 4개 범주 카드를 표시했다.
- 투자 상태 확정 버튼은 설정 영역과 연결된 compact action으로 정리했다.

### 2026-08-30~31 — 데이터 연결 구조 정리

- 대시보드·KOSPI·모의투자·MiroFish A2A의 데이터 접근을 `FINVERSE_DATABASE_URL` 기반 PostgreSQL 직접 조회로 통일했다.
- 원격 DB는 Tailscale 사설망에서만 접근하고, 로컬 개발은 SSH 터널을 사용할 수 있다.
- 원격 `.env`는 Docker 전용 값을 보존해야 하며, 비밀번호·API 키는 커밋·로그·문서에 남기지 않는다.
