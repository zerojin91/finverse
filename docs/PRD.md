## 1. 개요

### 1.1 한 줄 정의

FINVERSE는 시장 사건을 조건부 시나리오로 시뮬레이션하고, 그 결과를 사용자의 가상 금융 프로필에 적용해 **목표 영향과 인지 편향까지 되돌려주는** 금융교육형 AI 시뮬레이터다.

### 1.2 이 제품이 아닌 것

명시적 비목표다. 기능 논의가 이 선을 넘으면 되돌린다.

- 미래 가격·수익률을 단정적으로 예측하는 서비스가 **아니다.** 모든 전망은 조건부 밴드와 신뢰구간으로만 제시한다.
- 특정 금융상품을 추천하거나 매수·매도를 권유하는 서비스가 **아니다.**
- 실계좌를 연동하거나 민감 금융정보를 수집하는 서비스가 **아니다.** MVP는 가상 프로필만 사용한다.
- 로보어드바이저·자동매매가 **아니다.** 산출물은 실행이 아니라 판단 연습이다.

### 1.3 성공의 정의

MVP는 "KOSPI 하나를 이해 → 시뮬레이션 → 개인 영향 확인"까지의 **단일 흐름이 끊기지 않는지**를 검증한다. 자산군 확장은 이 흐름이 검증된 뒤의 일이다.

## 2. 문제 정의

### 2.1 관찰된 문제

금융소비자는 불확실성이 큰 상황에서 자신의 위험 감내 수준과 장기 목표에 맞지 않는 결정을 반복한다.

| 상황 | 반복되는 행동 | 작동하는 편향 |
| --- | --- | --- |
| 급등장 | 기회 상실 불안으로 추격 매수, 고위험 상품 집중 | 과신, FOMO, 군집행동 |
| 급락장 | 장기 계획을 포기하고 공포 매도로 손실 확정 | 손실회피 |
| 평시 | 대출 점검·비상자금·리밸런싱을 계속 미룸 | 현재편향, 판단 회피 |
| 정보 탐색 | 뉴스·핀플루언서·커뮤니티 의견을 자기 상황과 무관하게 수용 | 확증편향 |
| 손익 판단 | 매수가·최근 고점에 기준을 고정 | 기준점 의존 |

이 오류는 단기 투자 손실에서 끝나지 않고 부채관리·유동성·주거·노후 준비까지 훼손한다.

### 2.2 근본 원인

금융지식의 부족이 아니라 **예측 가능한 비합리성**이다. 원칙을 아는 것과 감정이 개입된 상황에서 원칙을 적용하는 것은 다른 능력이며, 후자는 반복 훈련으로만 길러진다.

### 2.3 기존 서비스가 비운 자리

| 서비스 유형 | 제공하는 것 | 비어 있는 것 |
| --- | --- | --- |
| 금융 뉴스 | 시장에서 무슨 일이 있었는가 | 그 사건이 내 자산·부채·목표에 주는 영향 |
| 증권 앱 | 실시간 가격과 손익 | 결정 **전에** 선택지별 위험을 비교할 수단 |
| 금융교육 | 올바른 원칙 | 감정이 개입된 상황에서의 적용 훈련 |
| 로보어드바이저 | 배분 결과·상품 제안 | 내가 왜 그 선택에 끌렸는지에 대한 설명 |
| 모의투자 | 종목 손익 경험 | 현금·부채·비상자금·주거 등 생활 금융 목표 |

결과적으로 사용자는 "이 상황에서 나는 왜 이런 선택을 하려 하는가", "이 선택이 내 목표에 어떤 위험을 만드는가"를 안전하게 점검할 기회를 얻지 못한다.

## 3. 타깃 사용자와 채널

### 3.1 1차 타깃 — 사회초년생·금융 초보 청년

첫 월급, 예·적금, ETF, 전세자금대출 등 금융 의사결정이 **동시에 시작되지만** 시장 용어와 위험 구조가 낯선 사용자.

이 세그먼트를 고른 이유:

- 앞으로 내릴 금융 의사결정의 **횟수가 가장 많다.** 편향 교정의 한계효용이 최대다.
- 금융 이력이 짧아 자신의 편향을 확인할 기회 자체가 없었다.
- 정보 접근성은 높지만 해석 기준이 없어 커뮤니티·핀플루언서 의존도가 가장 크다.
- 손실 경험 자산 규모가 작아 **지금 훈련하는 비용이 가장 싸다.**

### 3.2 2차 타깃 — 사회초년생 투자자

국내외 ETF·개별 주식에 이미 투자 중이나, 금리·환율·경기 변화가 자신의 포트폴리오와 목표 자금에 어떻게 연결되는지 알고 싶은 사용자.

### 3.3 채널

| 채널 | 역할 | 선택 이유 |
| --- | --- | --- |
| 모바일 웹 (1순위) | B2C 핵심 경험 전체 | 뉴스·커뮤니티를 소비하는 **그 순간, 같은 화면에서** 시뮬레이션으로 연결해야 편향이 발생하는 맥락에 개입할 수 있다. 설치·로그인 없이 즉시 진입 가능 |
| 데스크톱 웹 | 시나리오 비교·기관 교육 세션 | 다중 시나리오 동시 비교와 강의형 활용 |
| 기관 도입 (B2B2C) | 금융기관·기업·교육기관이 공통 시나리오 배포 | 개인 결과는 비공개, 기관에는 익명 집계만 |

## 4. 정보 구조

상위 메뉴는 **두 개만** 둔다. 시뮬레이션은 별도 탭이 아니라 시장 인사이트 안에서 이어지는 핵심 행동이다.

```text
FINVERSE
├── 시장 인사이트 (MARKET INSIGHT)   ← 기본 진입, 로그인·개인정보 불필요
│   ├── 시장 연결
│   ├── KOSPI LIVE + AI 요약
│   ├── 조건부 경로 차트 (신뢰구간)
│   ├── 가상 시뮬레이션 · 발생 가능 이벤트
│   ├── 시나리오 라이브러리
│   │   └── 시나리오 상세 (전제 / 예상 전개 / 4장 학습 / 편향 체크)
│   └── 내 시나리오 예측하기 (빌더)
└── 마이 금융 트윈 (MY FINANCIAL TWIN)  ← 선택적 진입
    ├── 나의 자산 현황
    ├── 포트폴리오 보유 현황
    ├── 시나리오별 내 자산 경로
    └── 금융 대가의 한마디
```

핵심 사용자 흐름:

```text
시장·종목 탐색
  → 섹터·이벤트·뉴스·AI 조건부 경로 이해
  → 시장 환경 시뮬레이션 (선택 또는 직접 생성)
  → 낙관·기준·위험 경로 비교
  → 마이 금융 트윈에 적용
  → 목표 영향·행동 편향 피드백
  → 다음 의사결정 연습
```

## 5. 기능 명세

### F-1. 시장 연결 (Market Connection)

KOSPI를 움직인 구성요소를 기여도 순으로 분해해 보여준다. "지수가 빠졌다"를 "무엇이 얼마나 끌어내렸다"로 바꾸는 화면.

| 항목 | 코드 | 값 | 등락률 | KOSPI 기여도 |
| --- | --- | --- | --- | --- |
| 삼성전자 | 005930 · KOSPI | 220,000원 | -13.39% | -1.68%p |
| SK하이닉스 | 000660 · KOSPI | 1,555,000원 | -14.65% | -2.42%p |
| 원·달러 환율 | USD/KRW | 1,462.50 | -0.41% | +0.12%p |
| 외국인 수급 | KOSPI | -5조 1,200억원 | 순매도 | -3.12%p |
| 반도체 지수 | KRX 반도체 | 4,318.72 | -13.82% | -3.46%p |

**요구사항**

- 기여도는 항상 %p 단위로 표시하고 상승/하락 색상(적/청, 국내 관행)을 구분한다.
- 모든 값에 기준 시각(`2026.07.28 KRX 장마감 기준`)을 병기한다. 시각 없는 숫자는 표시하지 않는다.

### F-2. KOSPI LIVE + AI 요약

- 현재 지수 `6,023.66`, 일간 `-10.84%`, `▼ 732.09`
- AI 한 줄 요약: 현재 국면과 전환 조건을 평서문으로 서술
- 요약문은 **반드시 조건절을 포함**한다. 예: "외국인 수급 회복 + SK하이닉스 영업이익 컨센서스 10% 이상 상회(약 70.5조원) + Microsoft·Meta AI CapEx 유지·확대가 **모두 확인되면** 1주 6,650 / 2주 7,050 / 1개월 7,500까지 반등 시도"
- 반증 지표를 같은 블록에 병기한다. 선행 PER 5.7~5.8배, RSI 31~34(과매도), MACD 하락, 연환산 변동성 80%

### F-3. 조건부 경로 차트

- 실제 경로(과거 32거래일)와 시나리오 경로를 하나의 축에 그린다.
- 시나리오 구간은 **단일 선이 아니라 신뢰구간 밴드**로 렌더링한다. 밴드 없는 경로는 표시 금지.
- 기본 시나리오 밴드 예: 1개월 중심값 7,500, 밴드 6,700~8,300

### F-4. 가상 시뮬레이션 · 발생 가능 이벤트

기간(1개월) 내 발생 가능 이벤트를 시간순으로 나열하고, 각 이벤트의 시나리오 포함 여부를 토글한다.

| 시점 | 분류 | 이벤트 | 추정 영향 |
| --- | --- | --- | --- |
| 8/4 전후 | 수급·실적 | 외국인 순매수 회복과 SK하이닉스 서프라이즈 | +10.0% |
| 8/11 전후 | 빅테크·AI | Microsoft·Meta AI CapEx 유지·확대 | +17.0% |
| 8/28 전후 | 분기점 | 20일 이동평균 7,232 회복 여부 | +24.5% |

**요구사항**

- 각 이벤트는 추정 영향과 함께 **인과 설명 문장**을 반드시 동반한다.
- 이벤트 토글 시 경로와 밴드가 재계산된다. 재계산 주체는 규칙 기반 엔진이며 LLM이 아니다(§7.3). **미구현** — 현재 배포본의 「시나리오에 포함됨」 버튼은 표시 전용이고 핸들러가 없다(`app/page.tsx:1104`). 이벤트 조합은 시나리오 단위로만 전환된다.

### F-5. 시나리오 라이브러리

준비된 시장 환경 3종. 카드 선택 시 발생 가능 이벤트와 조건부 경로가 열린다.

| 시나리오 | 기간 | 조건 태그 | 결과 |
| --- | --- | --- | --- |
| KOSPI 조건부 반등 | 1개월 | 외국인 순매수, AI CapEx | +24.5% |
| 반도체 실적 미스·AI CapEx 둔화 | 1개월 | SK하이닉스 실적 하회, AI 투자 재평가 | -13.8% |
| 외국인 매도·원화 약세 재확산 | 1개월 | 외국인 순매도, 원·달러·금리 | -8.7% |

### F-6. 시나리오 상세

`상세 보기` 진입 시 학습 콘텐츠를 제공한다. 구성 요소는 시나리오마다 동일한 스키마를 따른다.

- **시나리오 전제 / 예상 전개 / 신뢰구간** — 숫자와 조건
- **4장 구성 학습 아티클** — ① 급락 다음 날 무엇이 달라져야 하나 ② 실적은 숫자보다 기대의 방향을 바꾼다 ③ 멀티플이 다시 열리는 과정 ④ 언제 판단을 바꿀까. 각 장은 `근거(evidence)` 필드를 필수로 갖는다.
- **투자자 가이드** — `확인 전 / 조건 충족 / 조건 이탈` 3단계 스탠스별 행동과 근거
- **학습 질문** — 주제별 자문 질문
- **편향 체크** — `편향 / 빠지기 쉬운 함정 / 대응 기준` 3열
- **에이전트 인사이트** — 뉴스 수집가·애널리스트·퀀트 트레이더가 서로 다른 근거를 제시
- **리스크 포인트 / 반증 신호** — 시나리오를 즉시 보류해야 하는 조건 목록

> 설계 원칙: 상세 화면은 "이 시나리오가 맞다"가 아니라 **"이 시나리오가 틀렸다는 걸 언제 알 수 있는가"**를 같은 비중으로 보여준다.

### F-7. 내 시나리오 예측하기 (빌더)

사용자가 직접 시장 환경을 구성한다.

**입력**

- 환경 시드 다중 선택 (외국인 순매수 회복, SK하이닉스 실적 서프라이즈 등)
- 기간 선택 (기본 30일)
- 자연어 조건 프롬프트 — 예: "8월 말까지 외국인 수급과 반도체 실적이 KOSPI에 미치는 영향을 비교해줘."
- 참고 자료 업로드 (txt/md/csv/json 미리보기 지원)

**처리 — 6단계 지식그래프 구성 시각화**

빌더는 계산 과정을 감추지 않는다. 시드 → 노드 → 관계 → 경로로 확장되는 그래프를 단계별로 노출해 결과의 근거를 보여준다.

**출력**

- 사용자 지정 시나리오 카드가 생성되어 라이브러리·트윈에서 동일하게 사용된다.

### F-8. 마이 금융 트윈

- **포트폴리오 보유 현황** — 종목·현재가·비중·등락률(1D)·기여도(1D)

### 6.2 저장 규칙

- 모든 레코드에 **출처 / 수집 시각 / 관련 대상 / 영향 방향**을 함께 저장한다. 화면의 모든 숫자는 근거 레코드까지 추적 가능해야 한다.
- 경제지표는 발표일·기준일·단위·계절조정 여부·예상값·실제값·수정 발표 여부를 분리 저장한다.
- 뉴스는 제목만 저장하지 않는다. 원문 링크·발표 시각과 함께 **사실 / 해석 / 시장 반응을 분리**한다.
- 커뮤니티 데이터는 사실이 아닌 **심리 관측값**으로만 사용한다. 언급량 급증을 시장 방향과 동일시하지 않으며, 봇·중복 게시·소수 의견 과대표집 가능성을 함께 표기한다.
- 시장·보조 데이터의 값이 다르면 수집 시각·수정 여부·산출 기준을 함께 기록한다.

### 6.3 검색 원칙

```text
사용자 지정 정보          → 반드시 검색
분석에 필요한 누락 정보    → LLM이 판단해 추가 검색
영향이 작거나 근거 부족    → 중립 처리 (임의 추정 금지)
```

### 6.4 히스토리컬 데이터

- 가격은 일 단위 OHLCV를 기본으로 최소 1년, 가능한 한 길게 수집한다.
- 큰 상승·하락·추세 전환 시점의 뉴스·정책·경제 변화·수급·심리를 역추적해 원인을 분석한다.
- 과거 이벤트의 **영향 방향·강도·지속기간**을 확인해 유사 시나리오의 근거로 반영하되, 과거 결과를 미래의 정답으로 쓰지 않고 **현재 조건과의 차이를 함께 표시**한다.

### 6.5 핵심 관계

```text
외부 사건 → 경제 → 시장 → 사람들의 심리 → 시장
과거 유사 사례 → 현재 상황 해석
현재 시장 상황 + 사용자 조건 → 시뮬레이션 엔진 → 미래 시나리오
```

## 7. AI 설계

### 7.1 생성형 AI의 역할

| 역할 | 하는 일 | 산출물 |
| --- | --- | --- |
| A. 이해 | 뉴스·금융 용어를 사용자 눈높이로 번역, 시장 국면 한 줄 요약 | AI 요약 |
| B. 구조화 | 같은 원인의 뉴스를 하나의 이벤트로 묶고 관련 섹터·인과·추정 영향 태깅 | 이벤트 카드, 지식그래프 노드·엣지 |
| C. 시나리오 설계 | 자연어 조건을 엔진 입력 변수로 변환 | 시뮬레이션 파라미터 |
| D. 근거 서술 | 엔진 산출 경로를 4장 스토리로 설명하고 반증 신호를 명시 | 학습 아티클 |
| E. 관점 다변화 | 서로 다른 투자 원칙 관점으로 같은 시나리오를 재해석 | 대가 관점, 에이전트 인사이트 |
| F. 편향 코칭 | 선택 이유에서 FOMO·확증편향·기준점 편향을 탐지하고 대응 기준 제시 | 편향 체크 |
| G. 학습 확장 | 대상·난이도별 후속 미션·토론 질문 생성 | 학습 질문 |

### 7.2 멀티 에이전트 구성

`뉴스 수집가` / `애널리스트` / `퀀트 트레이더`가 동일 시나리오에 서로 다른 근거를 제시한다. 단일 서술이 정답처럼 읽히는 것을 구조적으로 막기 위한 장치다.

### 7.3 수치와 서술의 분리 — 가장 중요한 제약

> **지수·수익률·신뢰구간 등 모든 수치는 검증된 데이터 관계와 사전 정의 규칙·허용 범위 기반의 시뮬레이션 엔진이 산출한다. 생성형 AI는 수치를 만들거나 단정하지 않는다.**

- LLM 출력은 **근거 레코드가 존재하는 항목만** 화면에 노출한다. 근거 미확보 시 중립 처리한다.
- LLM은 엔진이 낸 숫자를 **설명**할 수 있을 뿐, 바꾸거나 새로 만들 수 없다.
- 이 경계를 흐리는 기능 요청은 거절한다.

## 8. 금융 안전 원칙

기능 설계·문구 작성 시 모두 적용되는 하드 제약이다.

1. 실제 투자 수익이나 시장 방향을 확정적으로 예측하지 않는다.
2. 전망은 단일 정답이 아닌 **조건부 범위와 신뢰구간**으로 제시하고, 산정 기준과 데이터 시각을 병기한다.
3. 모든 결과는 현재 조건과 과거 관계에 기반한 **교육용 가상 시나리오**임을 명시한다.
4. 실계좌 연동 및 민감 금융정보 수집 없이 가상 프로필로 운영한다.
5. 특정 금융상품을 추천하지 않고, 상황에 따라 비교할 수 있는 **금융 도구의 유형**만 안내한다.
6. 시나리오별 전제 조건·위험 요인·한계를 결과와 **같은 화면에** 표시한다.

### B2B2C 개인정보 보호

- 기관은 개인의 자산·부채·금융 목표·개별 시뮬레이션 결과를 **열람하지 않는다.**
- 기관 제공 정보는 참여율·완료율·시나리오별 학습 현황 등 **익명화된 집계 지표로 한정**한다.
- 기관 시나리오와 개인 프로필을 분리 저장해, 교육 운영자가 개인의 금융 상태를 추론할 수 없도록 설계한다.
