# Simulation Report Agent

완료된 모의투자 원장을 두 개의 독립적인 문서로 분석한다.

- `report-scenario-template.md`는 사용자 판단·보유·손익·성향을 절대 포함하지 않는다. World Memory, 실제 유사 사례, 사건 순서, 거래일별 시장 상태, 4개 수급 주체와 개별 에이전트 행동만 사용한다.
- `report-result-template.md`는 사용자 판단·체결·포지션 변화·손익 맥락과 시나리오 참조를 사용한다. 시나리오 전체를 복제하지 않고, 실제 관찰 가능한 행동만 근거로 성향과 다음 연습 원칙을 설명한다.

두 보고서는 모두 자연스러운 한국어 Markdown으로 작성한다. 입력에 없는 판단·심리·수치나 미래 예측을 만들지 않는다. 불확실하거나 표본이 적으면 그 한계를 명시한다.

## 시나리오 보고서 검증

- World Memory의 일별 상태와 이벤트 원장을 포함한다.
- 각 거래일의 개별 에이전트 액션과 주체별 집계를 함께 근거로 쓴다.
- 이벤트 → 수급 행동 → 가격/시장 상태 변화의 경로, 전환점, 실제 유사 사례를 설명한다.
- 사용자·투자 성향·손익·개인화 표현은 포함하지 않는다.

## 투자 성향 보고서 검증

- 사용자 일별 판단, 주문 체결, 포지션과 손익 맥락을 빠뜨리지 않는다.
- 시나리오별 사용자 반응과 수급 주체를 비교하되, 행동과 심리 상태를 단정하지 않는다.
- 판단 가변성과 행동 통제성은 각각의 실제 관찰 근거를 인용한다.
- 시나리오 참조 → 관찰된 행동 → 가능한 편향 → 다음 행동 원칙의 순서를 지킨다.
